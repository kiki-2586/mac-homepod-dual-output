本次更新让 Mac 内置扬声器和一只 HomePod 分别播放左右声道，同时沿用原生 AirPlay 连接，并保留 Mac 的音量与同步延迟调节。

## 新增与改进

- 在“原生 AirPlay 跟随 → 声道分配”中选择“立体声同播”“Mac 左 · HomePod 右”或“Mac 右 · HomePod 左”。停止后可交换左右。
- 分声道时临时替换原声，将选定声道送回当前 AirPlay 输出；停止、启动失败或输出断开后恢复原声，不更改系统默认输出，不启动 OwnTone。
- AirPlay 重放使用40ms缓冲，解决捕获与输出回调节奏不同导致的缺帧卡顿。
- 增加20ms软件音量淡变，修复停止过程中的音量／延迟操作竞态和路由变化提示被覆盖的问题。
- 分声道一直没有捕获数据时，约6–8秒后自动停止并恢复原声。

## 使用

1. 先在 Mac 的 TV App／系统声音中连接 HomePod，确认原生播放与画面正常同步。系统默认输出需为 AirPlay。
2. 选择“原生 AirPlay 跟随”，分左右时只勾选 Mac 内置扬声器，再选择声道分配并开始。
3. Mac 提前就增加延迟，落后就减少。本机验证值约2000ms，换设备或内容后可能需要调整。HomePod 音量继续在 TV／系统中调节。

## 安装与下载

适用于 Apple Silicon、macOS26及以上。退出旧版后，完整替换“应用程序”中的 `MacHomePod.app`，保留既有设备、音量与延迟偏好。

- `MacHomePod-0.3.0-arm64.zip`：完整应用，包含共同播放所需的 OwnTone 后端与许可证。
- `MacHomePod-0.3.0-source.zip`：对应 Swift 源码、构建脚本、补丁、15份固定第三方源码及配方和许可证。
- `SHA256SUMS-0.3.0.txt`：应用包与源码包的 SHA-256 校验值。

仍为 ad-hoc 签名、未经 Apple 公证的实验版本，下载后可能被 Gatekeeper 拦截。可按 README 在本机从源码构建；仅使用原生跟随不需要构建 OwnTone，Command Line Tools 即可，不要求完整 Xcode。不要关闭系统安全保护。

## 验证与限制

完整自动回归通过。2026-10-23在 MacBook Air（macOS26.6）与 HomePod（audioOS26.6）上，用 TV App 自制左右声道视频逐项实测：正向分配正确；交换后流畅且与画面基本同步；普通同播重听后两段两边都有声、流畅同步。60秒临时原型也通过连续播放听音验证。发布主程序与已安装、实测通过的0.3.0二进制一致。

启停附近仍可能有短暂切换声。同步依赖手动校准，未做声学量化保证；受保护内容和 App 内直传 AirPlay 可能无法捕获。此功能是普通左右立体声，不是 Apple 空间音频或头部追踪。
